# Security policy

This is a static personal site (HTML, CSS and JavaScript). There is no server, database, login or user data.

If you find a vulnerability, please report it privately:

- Email: farhan736hussain@gmail.com
- Or use GitHub's "Report a vulnerability" button under the Security tab.

Please do not open a public issue for security problems. I aim to reply within a few days. Testing is limited to the public site itself; no denial-of-service or social engineering, please.
