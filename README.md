# thecyberfarhan.github.io

My portfolio: [thecyberfarhan.github.io](https://thecyberfarhan.github.io). A static site built with [Astro](https://astro.build) and animated with [anime.js](https://animejs.com), deployed to GitHub Pages by a GitHub Action.

## Structure

```
src/pages/index.astro            home page (sections live in src/components/)
src/pages/writeups/index.astro   searchable list of every writeup
src/pages/writeups/[slug].astro  one page per writeup, built from the data file
src/pages/llms.txt.ts            machine-readable summary for LLM crawlers
src/data/site.ts                 all hand-written content: method, projects, tools, journey, contact
src/data/writeups.json           generated by scripts/sync-writeups.mjs, do not edit by hand
src/scripts/motion.ts            shared scroll reveals and count-ups
src/styles/global.css            design tokens and base styles
public/                          files served as-is: PDFs, icons, robots.txt, manifest, sw.js
scripts/sync-writeups.mjs        pulls writeups from github.com/thecyberfarhan/CTF-Writeups
.github/workflows/site.yml       sync + build + deploy, on push and every 3 hours
```

## Working on it

```bash
npm install
npm run dev        # http://localhost:4321
npm run sync       # refresh src/data/writeups.json from CTF-Writeups
npm run build      # static output in dist/
```

Writeup URLs keep the old `writeups/<name>.html` form (`build.format: 'preserve'`), so links shared before the rebuild still work.

`public/sw.js` is not a real service worker: the old site installed one that cached pages, and this file replaces it with one that clears those caches and removes itself.

## Accessibility and motion

Every animation respects `prefers-reduced-motion`: the scroll walkthrough becomes a plain list of the six steps and nothing animates. Content is never hidden without JavaScript for longer than a few seconds.
